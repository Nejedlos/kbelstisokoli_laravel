# Website Menu and Navigation

The menu structure determines how easily website visitors can access important information. In this section, you can manage links in the header and footer of the website.

## Where to Find the Section
In the administration, in the left menu under **System > Menu**.

## Menu Item Management
Each menu (e.g., "Main Menu", "Footer") contains a tree structure of items.
1. Click the name of the menu you want to edit.
2. In the **Menu Items** section, you can:
    - Add a new item.
    - Edit an existing link.
    - Change the order of items by dragging.
    - Create a submenu (nesting an item under another).

## Link Types
When creating a menu item, you can choose:
- **External URL**: Link to another website (e.g., cz.basketball).
- **Internal Route**: Link to a specific part of our website (e.g., News, Teams).
- **Open in New Window**: Useful for external links so the visitor doesn't leave our website.

## Recommendations
- **Conciseness**: Menu names should be short (one, max. two words).
- **Number of Items**: We recommend a max of 6-7 main items in the main menu; hide the rest in submenus.
- **Icons**: You can choose an icon for items to appear next to the text (we support Font Awesome).
