# Checklist: Start of a New Season

Rolling over the club into a new season is the most critical operation of the year. This checklist will help you not to forget anything.

## Phase 1: Preparation (July/August)
1. **Create Season**: In the **Seasons** section, create a new season (e.g., 2025/2026). Don't set it as active yet.
2. **Review Rosters**: In the **Teams** section, update the rosters. Players transitioning to older categories (e.g., from U14 to U15) should be moved.

## Phase 2: Data Rollover (August)
1. **Initialization**: For the new season, run the **Initialize Configurations** action. Select the ending season as the source. This will create a profile for all players for the new year.
2. **Review Tariffs**: Verify if membership fee amounts have changed. If so, adjust **Financial Tariffs** before generating payments.
3. **Activation**: Set the new season as **Active**. From this moment on, players will see the program for the new year in their member section.

## Phase 3: Finance (September)
1. **Generate Charges**: In the **Payment Charges** section, bulk generate charges for the first period of the new season.
2. **Review QR Codes**: Verify that QR codes for the new year's payment are correctly displayed to players in the member section.

## Phase 4: Sport (September)
1. **Match Synchronization**: If competitions are already drawn, run the synchronization with **cz.basketball** so the matches appear in the calendar.
2. **Training Plans**: Upload the new training schedule to the **Trainings** section.

## What if Something Goes Wrong?
If you find an error in the data after activating the season, you can return to the previous one at any time by setting it as active again. This will allow you to correct the data in the new one in peace.
