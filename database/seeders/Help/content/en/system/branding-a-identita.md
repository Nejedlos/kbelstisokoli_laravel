# Branding and Club Settings

Branding settings are the heart of the club's visual and technical identity in the KS system. Here you define data that populates the public website, payment instructions, and email notifications.

### Club Identity
In this section, you configure official information:
- **Club Name and Abbreviation:** Displayed in headers and page titles.
- **Logos:** The system requires several variants (for light/dark backgrounds, favicon, watermark).
- **Slogan:** The club's main motto visible on the homepage.

### Financial Data (Critical)
Information in this section directly impacts club finances:
- **Bank Account and Bank Name:** These details are automatically displayed to members in their profiles as payment instructions. If changed here, all new instructions will include the updated account information.
- **Variable Symbols:** The system uses internal numerical sequences for members based on the settings in this section.

### Contacts and Venues
- **Main Venue:** Name and address of the arena where the club plays home matches. This data is populated into the match details on the website.
- **GPS and Map:** Entering GPS coordinates and a Google Maps link allows fans and opponents to navigate easily.
- **Social Media:** Links to Facebook, Instagram, and YouTube, which appear in the website footer.

### SEO and Search
For good visibility on search engines like Google, it is necessary to fill out:
- **SEO Description:** A brief description of the club (150-160 characters).
- **Keywords:** Main topics (e.g., basketball Kbely, youth recruitment).
- **Robots:** Settings for whether search engines should index the site (on by default).

### Maintenance Mode
In the case of major technical shifts (e.g., season restart), you can switch the entire website to maintenance mode. Administration remains accessible, but the public will only see information about ongoing maintenance.
