# Scenario: Recruitment and Integration of a New Player

When a new interested party applies through the web, the process of their integration into the club begins. This guide will walk you through the steps from initial contact to the first payment.

## Step 1: Handling the Prospect (Lead)
1. In the left menu, open **People and Members > Recruitment Leads**.
2. Here you will find data from the interested party from the web form.
3. After the initial contact (e.g., after a trial training session), you can mark the prospect as "Processed".
4. **Attention**: The system does not automatically convert a lead into a user. You must create the user manually.

## Step 2: Creating a User Profile
1. Go to **People and Members > Users** and click on **Create User**.
2. Fill in the e-mail, first name, and last name.
3. If it is a child, also fill in the **Parents** section (if the parent is already in the system, select them, otherwise create a new one).
4. **Important**: Don't forget to assign a role to the user (usually `player` for players).

## Step 3: Assignment to a Team
1. In the user profile on the **Club** tab or in the **Teams** section, assign the player to a specific team.
2. Verify that the player has the correct season set.

## Step 4: Payment Setup
1. In the user profile (or in the season configuration section), set a **Financial Tariff** for the player (e.g., "Contributions - Youth").
2. Set the months from which the player should start paying (Billing start month).

## Step 5: Invitation to the System
1. After setting all the data, click the password reset/send action for that person in the user list (if they don't have access yet).
2. The player/parent will receive an e-mail with instructions on how to log in to the member section.
3. Done! The player is now part of the Sokoli locker room.
