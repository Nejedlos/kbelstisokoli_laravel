## Account security

Members without administration access sign in with a password by default. Two-factor authentication (2FA) is optional for them. Once enabled and confirmed, sign-in also requires an authenticator code or a single-use recovery code.

## Who must use 2FA

Every account with administration access must use 2FA, including administrators, coaches, editors, economists and custom roles with administration access permission. This also applies when a user has a player or parent role alongside an administrative role.

After entering your password, complete setup before continuing to any application section, including the member section. You may switch language or sign out. Accounts with active 2FA must verify their code before accessing security settings.

## Set up and manage 2FA

1. Open **My profile → Two-factor authentication** and choose activation or management. The dashboard reminder opens the same wizard.
2. Confirm your current password if requested; you will return to the wizard.
3. Enable 2FA and scan the QR code using an authenticator app, or enter the displayed key manually.
4. Confirm with the current six-digit code. An invalid code can be corrected on the same page.
5. **Copy or download your recovery codes** and store them securely. Each code works once. Continue to the application without another immediate challenge.

Ordinary members can leave unfinished setup and finish later. Until confirmation, they can still sign in using just their password. The profile shows that setup is pending.

## Recovery codes, trusted devices and disabling

The wizard lets you view or regenerate recovery codes after verification. Regenerating codes invalidates the previous ones immediately.

After successful 2FA, you can remember your own device for 30 days. A password change or 2FA reset can require verification again.

Ordinary members may disable optional 2FA from their profile after the required verification. Accounts with administration access cannot disable mandatory 2FA themselves.

## Troubleshooting

- **Lost phone:** Use a recovery code. If unavailable, contact an administrator for a reset. Accounts with administration access must then complete setup again.
- **Invalid code:** Check the account selected in your authenticator and automatic time settings on your phone.
- **Password reset:** Resetting the password does not remove active 2FA.
- **Cancel sign-in:** Signing out also cancels a pending 2FA challenge.
