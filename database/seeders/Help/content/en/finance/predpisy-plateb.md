# Finance Charges (Member Debts)

A finance charge is the basic building block of the financial module. It defines how much a specific member should pay, for what, and by when.

## How to Create a New Charge

1.  Go to **Finance -> Finance Charges**.
2.  Click on **New Charge**.
3.  **Member (User):** Search for and select the member you are issuing the charge to.
4.  **Charge Type:** Select a category (Membership Fee, Camp, Tournament, Other).
5.  **Title / Purpose:** Enter a clear description (e.g., "Membership Fees Autumn 2024"). This text will be visible to the member.
6.  **Total Amount:** Enter the amount in CZK.
7.  **Due Date:** Select the day by which the payment should be made.
8.  **Status:** Set to **Open (To be paid)** by default. If the charge is in "Draft", the member will not see it and payments cannot be allocated to it.
9.  **Visible to member:** Keep checked for the information to appear in the member section.

## Management and Filtering

In the list of charges, you can quickly identify non-payers using the **Status -> Overdue** filter. The system automatically marks charges as "Overdue" if the due date has passed and the amount is not fully paid.

> [!INFO]
> If a member pays only part, the charge status will automatically change to "Partially Paid" after allocation. Once the remaining balance is completed, the status will switch to "Paid".
