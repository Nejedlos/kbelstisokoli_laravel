# Financial Tariffs Management

Financial tariffs serve as a directory of amounts for recurring payments in the club, typically for membership fees. Correct tariff settings facilitate mass charge generation and maintain consistent prices across categories.

## How to Create a Tariff

1.  Go to the **Finance -> Tariffs** section.
2.  Click on **New Tariff**.
3.  Enter a **Name** (e.g., "U12 Membership Fees - Monthly").
4.  Enter the **Base Amount** in CZK.
5.  Select the **Unit** (Month or Season).
6.  Save the record.

## Using Tariffs

Tariffs are primarily used in the system as a reference value. When creating a specific charge for a member, you can start from the tariff, but the amount can be individually adjusted for each member (e.g., for a sibling discount).

> [!WARNING]
> Changing the amount in a tariff does not automatically change existing charges (debts). It will only affect newly created records.
