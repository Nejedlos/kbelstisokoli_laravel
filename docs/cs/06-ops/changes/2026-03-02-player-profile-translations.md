# Doplnění překladů hráčského profilu (02. 03. 2026)

## Popis změn
Byl doplněn chybějící překlad pro pole "Číslo dresu" v administraci hráčských profilů.

### Seznam úprav:
- **Lokalizace:**
    - Přidán klíč `jersey_number` do sekce `player_profile.fields` v češtině i angličtině.
    - Oprava zobrazení popisku pole v administraci (Filament).

## Technické detaily
- Upraveny soubory:
    - `lang/cs/admin.php`
    - `lang/en/admin.php`
