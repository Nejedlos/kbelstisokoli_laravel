# 3. Lidé a členové

Tato sekce je klíčová pro správu členské základny klubu, uživatelských účtů a hráčských profilů.

Nápověda > Lidé a členové

### Co zde najdete?
- **Uživatelé:** Centrální správa všech osob v systému (přihlašovací údaje, kontakty, role).
- **Hráčské profily:** Detailní sportovní údaje hráčů (výška, váha, dres, historie).
- **Zájemci (Leady):** Správa nově příchozích zájemců o členství v klubu.
- **Role a oprávnění:** Nastavení toho, kdo co může v systému dělat.

### Pro koho je sekce určena?
- **Administrátoři:** Kompletní správa uživatelů a jejich oprávnění.
- **Koučové:** Vyhledávání hráčů, kontrola kontaktních údajů svých svěřenců.
- **Editoři:** Práce s hráčskými profily pro webové prezentace.
