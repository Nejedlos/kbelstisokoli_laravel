# 4. Ekonomika

Tato sekce slouží ke správě financí klubu, členských příspěvků a plateb.

Nápověda > Ekonomika

### Co zde najdete?
- **Předpisy plateb:** Definice toho, kdo má kolik zaplatit (např. "Členský příspěvek Podzim 2026").
- **Platby:** Evidence skutečných příchozích plateb.
- **Finanční tarify:** Ceník příspěvků pro různé kategorie členů.

### Pro koho je sekce určena?
- **Administrátoři:** Nastavení tarifů a hromadné generování předpisů.
- **Ekonomové:** Každodenní správa a párování plateb.
- **Koučové:** (Náhled) Kontrola, zda mají jejich svěřenci zaplaceno.
