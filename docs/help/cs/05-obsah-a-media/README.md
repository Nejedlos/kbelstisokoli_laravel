# 5. Obsah a média

V této sekci spravujete to, co návštěvníci vidí na veřejném webu – články, galerie a další obsah.

Nápověda > Obsah a média

### Co zde najdete?
- **Novinky (Články):** Aktuální zprávy z klubu a reporty ze zápasů.
- **Galerie:** Fotogalerie z akcí a zápasů.
- **Stránky:** Statický obsah webu (O klubu, Kontakty atd.).
- **Knihovna médií:** Správa všech nahraných souborů a obrázků.
- **Menu:** Nastavení navigačního menu webu.

### Pro koho je sekce určena?
- **Editoři:** Hlavní uživatelé, kteří píší články a nahrávají fotky.
- **Koučové:** Mohou nahrávat fotky ze zápasů svého týmu do poolu.
- **Administrátoři:** Nastavení struktury webu a menu.
