# 8. Systém a údržba

Sekce pro technické nastavení a správu chodu celého systému.

Nápověda > Systém a údržba

### Co zde najdete?
- **Role a oprávnění:** Definice uživatelských skupin a jejich práv.
- **Auditní logy:** Záznamy o všech změnách v systému (kdo, co, kdy).
- **Logy 404:** Seznam nefunkčních odkazů na webu.
- **Přesměrování:** Správa URL přesměrování.
- **Plánované úlohy (Cron):** Přehled automatických procesů na pozadí.
- **Systémová konzole:** Nástroje pro technickou údržbu.

### Pro koho je sekce určena?
- **Administrátoři:** Hlavní techničtí správci systému.
- **Vývojáři:** Pro diagnostiku a řešení chyb.
