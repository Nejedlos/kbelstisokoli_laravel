# 2. Sportovní agenda

V této sekci spravujete veškeré sportovní dění v klubu. Patří sem správa týmů, zápasů, tréninků a docházky.

Nápověda > Sportovní agenda

### Co zde najdete?
- **Týmy:** Přehled všech aktivních i historických týmů.
- **Zápasy:** Plánování a výsledky odehraných utkání.
- **Tréninky:** Rozpisy tréninků a evidence docházky.
- **Sezóny:** Definice aktuálního období a historických sezón.

### Pro koho je sekce určena?
- **Trenéři / Koučové:** Každodenní práce s týmem, docházkou a zápasy.
- **Administrátoři:** Nastavení sezón a hromadná správa dat.
